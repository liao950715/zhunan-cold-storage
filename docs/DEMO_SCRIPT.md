# 10/2 展示腳本（5–8 分鐘）

**展示前 10 分鐘**
1. 開正式站 https://zhunan-cold-storage.liao950715.workers.dev（備援：本機 `npm run dev` → http://localhost:5173）。
2. 管理員登入 → 其他作業＞系統設定 → 「重置為展示資料」（或本機 `npm run demo:reset`）。
3. 開第二個分頁先登入 `staff`（展示工作人員視角），第一個分頁保留 `admin`。
4. 投影字級：Chrome 縮放 110%，並開啟左下「文字放大」。
5. 小抄：同步碼、admin/admin1234、staff/staff1234。

**備援**
- 網路不通：本機 `npm run dev`，同步碼在 `worker/.dev.vars`。
- 投影出問題：`playwright-report/`（含截圖）與預錄影片。
- 展示中操作失敗：看「目前步驟」提示列與紅色訊息，訊息會說明原因與怎麼辦；真的卡住就「重置為展示資料」重來。

**一句話結尾**：以前是「我記得有五籠」，現在是「甘藍菜 17 籠，在 A-01-03、A-01-04、A-01-05，最早 10/23 到期」。
